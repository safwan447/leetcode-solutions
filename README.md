# LeetCode Solutions

This repo contains my solutions to LeetCode problems, solved as part of daily practice to strengthen my DSA and problem-solving skills.

Each problem has its own folder containing:
- The solution code
- A short README explaining the approach, complexity, and any learnings

## Structure

Problems are organized by number, e.g. `0001-two-sum`, `0002-add-two-numbers`, and so on.

## Why this repo

Tracking consistent practice, revisiting patterns, and building a public log of progress.
